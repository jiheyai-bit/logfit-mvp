01 · PROBLEM & USER

기록은 필요하지만,
입력하는 순간이 번거롭다.

사용자

식사·운동·휴식을 챙기고 싶지만 업무 중 정형화된 앱 입력을 부담스러워하는 직장인.

문제의 순간

기록하려고 앱을 열어도 식사 종류, 운동 시간, 날짜를 각각 입력해야 해 기록이 미뤄진다. 나중에는 무엇을 했는지 기억이 흐려진다.

기획 가설 · 사용자가 평소 말하듯 한 문장으로 입력하고, 저장 전 직접 확인할 수 있으면 기록의 부담과 잘못된 확정을 함께 줄일 수 있다.

01

한 문장 기록

03 · HUMAN + HERMES

자동화할 일과
승인할 일을 나눈다.

HERMES가 하는 일

분해 · 정리 · 집계

  • 한 문장을 식사·운동·휴식 기록으로 파싱
  • KST 기준 날짜와 운동 시간을 구조화
  • 확인된 데이터만 하루·7일 요약으로 집계
사람이 하는 일

확인 · 수정 · 승인

  • 추출된 날짜·내용·시간을 원문과 대조
  • 불확실한 기록을 수정하거나 삭제
  • 확인한 기록만 저장하고 결과를 해석

승인 경계 · 날짜가 모호하거나 완료 여부가 불확실하면 사실로 확정하지 않는다. 시스템은 확인 필요 상태를 보여주고, 최종 저장은 사람의 확인 뒤에만 실행한다.

04 · INPUT → OUTPUT

원문은 남기고,
확정된 구조만 요약한다.

실제 입력 예시
“오늘 점심은 김치찌개를 먹고 저녁에 요가 40분 했어.”

원문은 각 레코드에 그대로 보존해 사용자가 결과를 대조할 수 있다.

확인 화면의 출력
종류날짜내용상태
식사오늘(KST)점심 · 김치찌개저장 전 확인
운동오늘(KST)요가 · 40분저장 전 확인
날짜

KST 기본. 어제·명시 날짜를 해석하고 모호하면 추측하지 않음.

저장

사용자가 확인한 정규화 기록만 localStorage에 저장.

집계

예정 운동 시간과 불확실 기록은 완료 합계에서 제외.

최종 목표 · LogFit의 최종 목표는 기록을 자동화하는 AI에서 일상적인 건강관리 의사결정을 지원하는 AI Wellness Agent로 발전하는 것이다.

이번 MVP는 자연어 기반 식사·운동 기록의 구조화, 저장 및 일간·주간 집계 정확성을 검증한다. 향후 수면 데이터, 운동량, 식습관, 보유 식재료와 개인 선호도를 단계적으로 연계하여 생활 패턴에 맞는 식단을 추천하는 서비스로 확장할 계획이다.
